# Salon Landing Page — Demo

A responsive one-page landing page for a fictional hair salon, built with HTML, CSS, and JavaScript.

## Live Demo

[View Live Demo](https://krabz11-lgtm.github.io/salon-landing-page/)

## Tools Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
- Responsive mobile-first design

## Features

- Service list with ZAR pricing
- WhatsApp booking buttons
- Contact section
- Mobile-friendly layout
- Simple, business-focused design

## How It Works

Visitors can browse the salon services and tap a service to open WhatsApp with a pre-filled booking message.

## Note

This is a demo project created for portfolio purposes. It uses fictional business information and sample content.
